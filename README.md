# Registration Form

This project is a simple **Registration Form** created using Visual Studio 2022. It demonstrates how to create a form, receive user input, and display the submitted data using a button event.

## Description

The application allows users to fill in their registration information through several input fields. When the **Register** button is clicked, the program retrieves the entered data and displays it in a popup message.

## Features

* Registration form for user input
* Input fields for registration data
* **Register** button with click event
* Popup message displaying the submitted data
* Simple and user-friendly interface

## How It Works

1. Open the registration form.
2. Fill in the required information.
3. Click the **Register** button.
4. The program retrieves the data entered in the form.
5. A popup message appears and displays the submitted information.

## Example

After filling in the registration form:

```text
Name       : Me
NIM        : 123456
Major      : Informatics Engineering
```

Clicking the **Register** button will display a popup containing the entered information.
